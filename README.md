# Schedule I 한글패치 (비공식)

<img width="1920" height="1080" alt="{A50707AD-12B4-482B-8CA8-96F1409AC7BA}" src="https://github.com/user-attachments/assets/3256d8d2-eb2d-4bc2-a8c3-87d871081dcb" />


[Schedule I](https://store.steampowered.com/app/3164500/Schedule_I/) 게임의 비공식 한글패치입니다.

- 번역 항목 **58,000개 이상** (대사, UI, 아이템 설명, 퀘스트, 튜토리얼 등)
- 가격·이름·장소가 실시간으로 끼어드는 문장까지 처리하는 **정규식 조립 번역**
- 일반 번역기가 놓치는 UI까지 잡아주는 **전용 보조 플러그인** (KoreanTextFixer)
- **을지로체 폰트** 적용 (선택)
- 게임 플레이 중에는 인터넷 번역 서비스를 쓰지 않음 — **번역은 완전 오프라인 작동**
- **넥서스 모드(MelonLoader)와 함께 사용 가능** — 설치기가 MelonLoader를 감지하면 자동으로 맞춰 설치

## 다운로드

**[⬇ 최신 버전 다운로드 (ZIP)](https://github.com/enddl3788/Schedule_I_Korean/archive/refs/heads/main.zip)** ← 이 링크를 누르면 바로 받아집니다

깃허브가 익숙하지 않아도 괜찮습니다. 위 링크를 누르면 ZIP 파일이 바로 다운로드됩니다.
직접 찾아 받으려면 이 페이지 위쪽의 초록색 **`< > Code`** 버튼 → **`Download ZIP`** 을 누르세요.

받은 ZIP은 **압축을 풀어야** 합니다. (압축 안에서 바로 실행하면 작동하지 않습니다)
파일 우클릭 → "압축 풀기" 또는 반디집·알집 등으로 풀어주세요.

## 설치 방법 (3단계)

1. 게임을 완전히 종료합니다.
2. 압축을 푼 폴더에서 **`설치.bat` 을 더블클릭**합니다.
3. 중간에 묻는 질문은 그냥 **엔터**를 누르면 됩니다. 끝!

**미리 준비할 것은 없습니다.** 모드 로더나 번역기를 직접 설치하지 않아도 되며, `설치.bat`이 알아서 처리합니다.

### 넥서스 모드(MelonLoader)를 같이 쓰는 경우

넥서스의 Schedule I 모드는 대부분 **MelonLoader**로 작동합니다. 한글패치의 기본 방식(BepInEx)과 MelonLoader는 **동시에 켤 수 없어서**, 둘 다 깔려 있으면 한글패치가 작동하지 않았습니다.

이제 `설치.bat`이 알아서 처리합니다.

- **MelonLoader가 이미 깔려 있으면** → 자동으로 MelonLoader 방식으로 설치하고, 충돌하는 BepInEx는 꺼 둡니다.
- **아무것도 없는 새 설치라면** → "넥서스 모드도 함께 쓰실 건가요?"라고 묻습니다. 모드를 쓸 거라면 `M`, 한글패치만 쓸 거라면 엔터.
- **한글패치를 먼저 깔고 나중에 MelonLoader를 설치했다면** → `설치.bat`을 한 번 더 실행하세요. 자동으로 전환됩니다.

넥서스 모드는 평소처럼 게임 폴더의 `Mods` 폴더에 넣으면 한글패치와 함께 작동합니다.
MelonLoader를 처음 설치하면 **첫 게임 실행에 1~3분** 더 걸립니다(게임 코드 변환 과정, 인터넷 필요). 두 번째부터는 평소 속도입니다.

> **폰트는 왜 물어보나요?**
> 게임 기본 폰트에는 한글이 없어서, 폰트를 바꾸지 않으면 번역된 글자가 네모(ㅁ)로 깨져 보일 수 있습니다.
> 다만 이 작업은 게임 원본 파일 1개를 수정하기 때문에(원본은 자동 백업) 동의를 받고 진행합니다.
> 건너뛰었다면 나중에 `폰트적용.bat`으로 언제든 적용할 수 있습니다.

> Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.

### 첫 설치에는 인터넷이 필요합니다 (약 21MB)

아래 구성 요소는 원 제작자의 공식 출처에서 직접 받는 것이 신뢰성·라이선스 측면에서 낫기 때문에, 패키지에 넣지 않고 설치 시 자동으로 내려받습니다. **이미 설치되어 있으면 건너뜁니다** (두 번째 실행부터는 다운로드 없음).

| 자동 다운로드 | 출처 | 크기 |
|---|---|---|
| BepInEx (IL2CPP) — 기본 방식 | builds.bepinex.dev 공식 빌드서버 | 약 20MB |
| MelonLoader 0.7.3 — 넥서스 모드 방식 (없을 때만) | GitHub 공식 릴리스 | 약 20MB |
| XUnity.AutoTranslator 5.6.1 (방식에 맞는 버전) | GitHub 공식 릴리스 | 약 0.7MB |

나머지는 전부 `payload` 폴더에 **동봉되어 있어 다운로드가 필요 없습니다** — 번역 파일 4종, KoreanTextFixer 플러그인(BepInEx판·MelonLoader판), 번역기 설정, 을지로체 폰트, 폰트 교체 도구(AssetsTools.NET·classdata.tpk).

특히 **`폰트적용.bat`은 인터넷 접속을 전혀 하지 않습니다.**

## 게임이 업데이트되면

번역이 풀리거나 폰트가 원래대로 돌아올 수 있습니다. **`설치.bat` → `폰트적용.bat`** 을 다시 실행하면 복원됩니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 설치.bat이 바로 꺼짐 | ZIP 압축을 풀지 않고 실행한 경우입니다. 압축을 풀고 다시 실행하세요 |
| "게임 파일을 찾지 못했습니다" | Steam이 기본 위치가 아닌 곳에 설치된 경우입니다. 안내에 따라 게임 폴더 경로를 직접 입력하세요 (Steam에서 Schedule I 우클릭 → 관리 → 로컬 파일 보기) |
| 번역이 하나도 안 나옴 | `설치.bat` 재실행 후 게임 재시작 |
| 넥서스 모드를 깐 뒤로 번역이 안 나옴 | MelonLoader와 BepInEx가 충돌한 상태입니다. `설치.bat`을 다시 실행하면 MelonLoader 방식으로 전환됩니다 |
| 글자가 네모(ㅁ)로 깨짐 | `폰트적용.bat` 실행 |
| 게임 업데이트 후 다시 네모(ㅁ)로 깨짐 | 업데이트가 폰트 파일을 원본으로 되돌립니다. `폰트적용.bat`을 다시 실행하세요 |
| 일부만 영어로 나옴 | `_AutoGeneratedTranslations.txt` 삭제 후 재시작 (BepInEx: `BepInEx\Translation\ko\Text\` / MelonLoader: `AutoTranslator\Translation\ko\Text\`) |
| 게임이 이상해짐 | `잠금해제.bat` 실행 → Steam 게임 파일 무결성 검사 |
| 원래대로 되돌리기 | `잠금해제.bat` → 무결성 검사 → `BepInEx`·`AutoTranslator` 폴더와 `winhttp.dll` 삭제 (MelonLoader 방식이었다면 `Mods` 폴더의 `KoreanTextFixer.dll`·`XUnity.AutoTranslator.Plugin.MelonMod.dll`도 삭제) |

## 게임 중 단축키

- `Alt + T` : 번역 켜기/끄기 (원문 확인)
- `Alt + R` : 번역 파일 다시 불러오기

## 알려진 한계

- 메인 화면의 **Community Vote 배너**는 개발사 서버에서 실시간으로 받아오는 콘텐츠라 번역되지 않습니다.
- 플레이어가 직접 지은 이름(믹스 이름 등)은 번역 대상이 아닙니다. 단, 게임이 자동 생성한 이름(예: Purple Cake)은 번역됩니다.

## 저장소 구조

```
설치.bat                  ← 한글패치 설치 (더블클릭) — 로더 판단·폰트 적용까지 처리
폰트적용.bat              ← 폰트만 따로 적용하고 싶을 때
잠금해제.bat              ← 문제 시 설정 잠금 해제
install.ps1               ← 설치 스크립트 본체
font_patch.ps1            ← 폰트 패치 스크립트 본체
unlock.ps1                ← 잠금 해제 스크립트 본체
common.ps1                ← 게임 경로·로더 감지 공통 함수
payload/                  ← 번역 파일, 설정, 폰트, 플러그인 (melon/ = MelonLoader판 플러그인)
src/KoreanTextFixer       ← 보조 플러그인 C# 소스 (BepInEx판 빌드 + 공통 로직)
src/KoreanTextFixer.Melon ← 같은 소스로 MelonLoader판을 빌드하는 프로젝트
FONT_LICENSE.md           ← 폰트 라이선스 고지
```

## 번역 개선에 참여하기

오역·미번역 수정, 더 자연스러운 표현 모두 환영합니다. 이 저장소는 MIT 라이선스라 **자유롭게 포크해서 고쳐도 됩니다.** 고친 내용을 Pull Request로 보내주시면 검토 후 반영하겠습니다.

- 번역은 `payload/Text/` 의 텍스트 파일에 `영어원문=한국어` 형식으로 들어 있습니다.
  - `Korean_Base.txt` 기본 UI·대사, `Korean_Extracted.txt` 게임에서 추출한 문장, `Korean_Composites.txt` 이름·지역 조합, `Korean_Templates.txt` 숫자·이름이 끼어드는 문장용 정규식 규칙
  - 줄바꿈은 `\n`, 원문에 `=`가 있으면 `\=`로 씁니다.
- 게임 중 `Alt + R`을 누르면 파일을 다시 읽어서, 게임을 껐다 켜지 않고 바로 확인할 수 있습니다.
- 보조 플러그인을 고치려면 `src/` 참고: BepInEx판은 `src/KoreanTextFixer`, MelonLoader판은 `src/KoreanTextFixer.Melon` 에서 `dotnet build -c Release -p:GameDir="게임 폴더"`로 빌드합니다. (MelonLoader판은 MelonLoader로 게임을 한 번 실행해 `MelonLoader\Il2CppAssemblies`가 생성된 상태여야 합니다)
